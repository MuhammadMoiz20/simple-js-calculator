# simple-js-calculator

a basic calculator written in plain js/html/css. no frameworks.

## features
- four operations with operator precedence (does * / before + -)
- decimal numbers
- keyboard input (digits, ops, enter, backspace, escape)
- last 5 history
- clear / clear-entry / backspace

## run
just open `index.html` in a browser.
